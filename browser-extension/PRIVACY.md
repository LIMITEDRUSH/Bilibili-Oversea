# Bilibili-oversea 浏览器扩展隐私说明

Bilibili-oversea 不会把用户数据传给开发者、第三方分析服务或广告商，也不出售数据。扩展不包含遥测、广告、远程代码或开发者控制的服务器。

为了完成用户明确启用的 CDN 观测、测速和切换功能，扩展只在用户设备本机处理以下信息：

- `chrome.storage.local`：只保存启停、运行模式、手动目标、禁用的候选 host，以及有时限的主机测速摘要和时间戳；不保存完整媒体 URL、签名、Cookie 或页面内容。
- 内存中的标签页状态：保存当前标签页观测到的 CDN host、当前 `playurl` 媒体 URL、测速结果和已卡顿候选。完整媒体 URL 在内容脚本与后台间临时传递；不持久化，关闭标签页或退出浏览器后会消失。后台重启后，内容脚本可从本页内存重新报告当前视频地址，无需额外下载。
- Chrome 会话网络规则：播放重定向仅对明确的 B 站播放标签页、由 `bilibili.com` 发起且目标属于 `bilivideo.com` 的媒体相关请求生效。另有仅限本扩展发起、目标属于 `bilivideo.com` 的测速 Referer 规则，不修改网页发出的请求。规则在浏览器会话结束时清除。

完整测速请求预算为最多 8 个候选各 128 KiB 初筛，前三名各 1 MiB 复测，合计约 4 MiB；轻量复核仅两个节点各 256 KiB，合计 512 KiB。实际网络流量含协议开销，服务器忽略 Range 时会尽早取消读取，但不能把请求预算视为传输字节的绝对上限。候选节点会像正常播放一样看到用户 IP 和带签名的媒体请求；测速不发送 Cookie，数据不经过扩展作者的服务器。

扩展不会读取或修改 Cookie，不会访问浏览记录，不会使用代理权限，也不会处理其他网站的请求。

## Chrome Web Store Limited Use

扩展对 B 站播放页和媒体请求信息的使用仅限于提供用户可见的 CDN 观测、测速、切换和卡顿恢复功能。这些信息不会用于广告、画像、信用评估或其他无关用途，不会出售，也不会允许开发者或第三方人工读取。

用户可以随时在弹窗中停用功能。移除扩展会同时清除本地配置与学习记录。
