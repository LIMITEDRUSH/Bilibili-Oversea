Bili CDN Auto

浏览器直接安装扩展；iPhone 选择你正在使用的网络工具导入。所有测速在本机完成。

浏览器

下载 Chrome / Edge 扩展

解压后在扩展管理页面开启开发者模式，选择“加载已解压的扩展程序”。安装后默认自动模式。

iPhone / iPad 一键导入

导入 Surge导入 Loon 导入 Shadowrocket导入 Stash Quantumult X 配置链接

导入后必须在所选 App 内生成自己的 MITM 证书，并在 iOS 设置中信任。不要安装他人提供的共享证书。

点原版哔哩哔哩自动启动

安装“连接 VPN”快捷指令

安装后只需创建一次个人自动化：快捷指令 → 自动化 → App → 哔哩哔哩“打开时” → 立即运行 → 运行这个快捷指令。

它使用 iOS 原生“连接 VPN”动作，不会先跳到 Shadowrocket、Surge、Loon 或 Stash；打开原版哔哩哔哩时仍停留在 App 内，首个视频请求会自动触发 CDN 优选。如果有多个 VPN，请在快捷指令的“连接 VPN”动作中选中你使用的网络工具。

快捷控制

重新测速 自动模式 原始 CDN 查看状态

这些地址只会被已安装的本机脚本接管，不会连接外部服务器。网络工具未启动时不会生效。
