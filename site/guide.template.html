iOS 完整安装与自动启动教程

最终效果：直接点击原版哔哩哔哩 App，iOS 自动连接配置；播放视频时自动实测并选择 CDN。

返回安装页下载连接 VPN 快捷指令

开始前

  • 推荐 iOS/iPadOS 16.4 或更高版本。
  • Surge、Shadowrocket、Loon、Stash 任选一个，不要同时连接多个 VPN。
  • 网络工具中应已有可正常使用的主配置；本工具不提供代理节点或订阅。
  • 配置只导入一次，之后打开 B 站不会重复安装。

1. 导入配置

选择你实际使用的一款工具：

导入 Shadowrocket导入 Surge导入 Loon导入 Stash

Shadowrocket

  1. 点击上方按钮并允许 Safari 打开 Shadowrocket。
  2. 确认添加 Bili CDN Auto 模块。
  3. 在配置/模块页面确认模块已启用；回到首页选择平时使用的配置或节点。

Surge

  1. 点击“导入 Surge”，在模块安装页确认。
  2. Surge → 当前配置 → 模块，确认 Bili CDN Auto 已启用。
  3. 首次使用保持默认参数。

Loon

  1. 点击“导入 Loon”，确认添加插件。
  2. Loon → 配置 → 插件，确认 Bili CDN Auto 已启用。

Stash

  1. 点击“导入 Stash”，确认安装 Override。
  2. Stash → 覆写/Override，确认该覆写已启用，且原有主配置仍处于选中状态。

2. 安装并信任自己的证书

在所选客户端里找到 MITM、HTTPS 解密、证书或 CA Certificate：

  • Shadowrocket：设置 → 证书 → 生成新的 CA → 安装。
  • Surge：首页/更多 → MitM → 生成新的 CA → 安装。
  • Loon：配置/设置 → MitM → 证书 → 生成并安装。
  • Stash：首页 → MitM → CA 证书 → Stash Generated CA → 安装证书。

然后依次进入：设置 → 通用 → VPN 与设备管理 → 安装已下载的描述文件；再进入设置 → 通用 → 关于本机 → 证书信任设置，为该根证书开启完全信任。最后回到客户端确认 MitM/HTTPS 解密已开启。

只使用自己设备上的客户端生成的 CA。不要安装或共享他人的证书、私钥或 .p12 文件。

3. 首次连接并验证

  1. 在网络工具首页启动连接；首次使用时允许 iOS 添加 VPN 配置。
  2. 点击下方“查看状态”，出现含 "ok": true 的 JSON，说明控制脚本已加载。
  3. 打开哔哩哔哩，播放未完整缓存的视频 10–20 秒。
  4. 再次查看状态；selectedHost 应出现当前节点，scores 会显示测速结果。
查看状态重新测速

4. 安装快捷指令

  1. 点击这里安装 BiliCDNAuto-ConnectVPN。
  2. 在快捷指令 App 中确认它只有一个系统“连接 VPN”动作，然后添加。
  3. 如果有多个 VPN，编辑快捷指令，在动作中选中承载 Bili CDN Auto 的客户端。
  4. 手动运行一次并允许连接，确认 VPN 可以正常启动。

该快捷指令不会打开网页或代理客户端；它使用 iOS 原生动作在当前 App 内连接 VPN。

5. 创建“打开哔哩哔哩时”自动化

  1. 快捷指令 App → 自动化 → 右上角 + → App。
  2. 选择“哔哩哔哩”，勾选“打开时”。
  3. 选择“立即运行”；运行通知可按需关闭。
  4. 新建空白自动化 → 添加“运行快捷指令”。
  5. 选择 BiliCDNAuto-ConnectVPN，点击完成。

现在停止 VPN 并关闭 B 站测试。直接点击原版哔哩哔哩图标，VPN 应自动连接，画面仍停留在 B 站。个人自动化由 iOS 保护，下载文件不能替你静默创建，所以这一步只需手动确认一次。

6. 后续操作

  • 日常：直接打开哔哩哔哩。
  • 网络改变或变慢：点“重新测速”，再播放未缓存的片段。
  • 临时停用改写：点“原始 CDN”。
  • 恢复智能选择：点“自动模式”。
  • 不要每次打开 App 都强制重测；自动模式会复用仍然健康的结果。

7. 排错

VPN 没自动连接

先手动运行快捷指令；检查自动化是否启用、触发 App 是否正确、是否选了“立即运行”，以及“连接 VPN”动作是否指向正确配置。

VPN 已连接但没有 selectedHost

检查模块/插件/Override、MITM 开关及证书完全信任。换一个新视频或未缓存片段，再点一次重新测速。

出现证书错误或无法联网

立即停止 VPN，禁用模块后测试；检查证书是否属于自己的客户端，以及是否和其他重写规则冲突。

仍然不快

候选 CDN 在当前运营商上的线路可能相近，或瓶颈不在 CDN。工具无法保证每条视频都改善。

8. 卸载恢复

  1. 删除“哔哩哔哩打开时”个人自动化。
  2. 删除连接 VPN 快捷指令。
  3. 在网络工具中禁用或删除 Bili CDN Auto。
  4. 若不再使用 MitM，可删除对应证书描述文件。
  5. 停止 VPN；B 站恢复原始 CDN 行为。
